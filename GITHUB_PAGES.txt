NEXUS-X PWA — SUBIDA RÁPIDA

1) Abrí el repositorio:
   https://github.com/miqueas80/laboratorio-escolar

2) Subí TODO el contenido de este paquete a la raíz del repositorio.

3) En GitHub:
   Settings → Pages
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Save

4) Esperá la publicación y abrí:
   https://miqueas80.github.io/laboratorio-escolar/

5) En Android:
   Chrome → menú ⋮ → Agregar a pantalla de inicio / Instalar aplicación.

NO subas una API key al repositorio.
La clave de Gemini se introduce dentro de NEXUS-X y queda en el almacenamiento local del dispositivo.
